# 模型与数据投毒

> OWASP LLM04:2025。攻击者操纵训练/微调数据，在模型内部埋下隐蔽行为，触发时才显现。

## 1. 训练数据投毒

- **语料投毒**：向爬取语料库贡献恶意数据，基座模型学习隐藏行为
- **后门/木马**（Backdoor/Trigger-based）：特定触发词触发恶意行为，平时表现正常
- **Sleeper Agent（休眠代理）**：训练时植入"在某条件下才激活"的行为，上线很久后才被激活
- 数据中介供应链：从 GitHub、数据经纪人购买的语料可能被污染

## 2. 微调投毒

- 向微调 API（OpenAI Fine-Tuning、Anthropic 等）提交**通过审核但教会模型对抗行为**的样本
- 通过微调隐藏系统提示规避/撤销安全对齐
- 对开源权重微调后，上游权重本身可能含后门

## 3. 反馈循环投毒（Feedback-Loop Poisoning）

- 用户反馈（点赞/踩）驱动后续训练 → 协同攻击者操纵信号
- 在线学习场景：恶意用户不成比例地影响模型
- 防御：反馈限流、异常提交审计、多样性要求

## 4. RAG 侧投毒（交叉引用）

见 [RAG 与向量库攻击](rag-vector-attacks.md)——投毒文档进入知识库被频繁检索。

## 5. Tokenizer 攻击

- 恶意 tokenizer 将敏感词拆成异常 token 序列，绕过安全过滤器
- 词表污染：让目标词映射到无害 token

## 6. 检测要点

- 评估集采用**对抗性保留集**（held-out adversarial set），非仅分布内测试集
- Canary 查询：应产生一致回答的查询出现漂移即告警
- 输出统计异常检测（随时间）
- 数据源去重、抽查、版本控制
- 微调前后对基准模型做差异评估（diff against reference model）
