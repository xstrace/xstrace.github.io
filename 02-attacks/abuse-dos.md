# 滥用与成本攻击

> OWASP LLM10:2025（无界消耗），原 LLM04 模型 DoS 的扩展——资源管理 + 意外成本，是大规模部署中最实际的损失。

## 1. 无界消耗（Unbounded Consumption）

攻击者耗尽配额/算力/成本：

- **超长输入**：巨型上下文耗尽 token 配额
- **超长输出**：诱导模型输出海量内容
- **无限循环**：Agent 循环执行工具调用（token + API 调用成本）
- **暴力重试**：越狱/注入反复尝试直到成功（成本不高但对攻击者零成本）
- **并发放大**：多账号/分布式放大

## 2. 针对性资源攻击

- 让 Agent 调用昂贵工具（大模型推理、外部付费 API、数据库全表扫描）
- 诱导 Agent 执行资源密集型操作（递归、大文件处理）
- 触发"重试循环"（模型报错 → 自动重试 → 成本指数上升）

## 3. 业务滥用

- 生成式滥用：批量生成内容（垃圾邮件、刷评论、爬虫）
- 身份绕过下的免费额度消耗
- 缓存毒化 + 缓存放大

## 4. 防御要点

| 控制 | 说明 |
|---|---|
| 每用户/每会话速率限制 | 基础门槛 |
| 每租户成本上限 + 硬关停 | 防账单炸弹 |
| 输入/输出长度上限 | 双向限制 |
| 会话工具调用次数上限 | 防 Agent 循环 |
| 循环检测 | Agent 框架内置死循环识别 |
| 工具调用超时 | 防挂起调用 |
| 分层模型路由 | 便宜模型处理简单请求，昂贵模型受限 |
| 用量异常监控 | 在账单到达前发现异常（token 消耗告警） |
| 频率/行为基线 | 偏离即告警 |

## 5. 数据点

- 典型攻击在正常业务流量中难以被发现——监控必须基于基线而非阈值
- Agent 时代：一次成功的注入可利用 Agent 循环把成本放大 10-100 倍
