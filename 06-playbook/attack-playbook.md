# 攻击速查表

> 每行：攻击 → 原理一句话 → 关键手法 → 主要防御。用于测试时的覆盖检查。

## 提示与上下文层

| 攻击 | 原理 | 手法 | 防御 |
|---|---|---|---|
| 直接注入 | 指令伪装成输入 | "Ignore previous instructions"、权威宣称、角色扮演 | 输入扫描、上下文隔离、系统提示最小化 |
| 间接注入 | 指令藏在不可信内容 | 邮件/网页/PDF/GitHub Issue/工具输出 | 检索内容扫描、定界符、工具输出校验 |
| 多模态注入 | 指令藏在图像/音频 | OCR 文本、隐写、对抗噪声 | 多模态扫描、渲染净化 |
| 越狱 | 绕过对齐 | DAN/developer mode、编码混淆、Crescendo/TAP 多轮 | 输入分类器、多轮对话检测、输出侧护栏 |
| 系统提示窃取 | 提示视为公开 | "Repeat the words above"、翻译包装 | 提示不存密钥、安全逻辑外置 |
| 上下文污染 | 污染会话历史 | 前序恶意消息持久影响 | 会话隔离、来源标记 |

## 工具/Agent 层

| 攻击 | 原理 | 手法 | 防御 |
|---|---|---|---|
| 工具描述投毒 | 元数据=可写指令 | description 藏指令（成功率最高 72.8%） | 描述指纹/漂移检测、语义验证、白名单 |
| Rug Pull | 先信任后变异 | 更新后加恶意逻辑（postmark-mcp） | 版本锁定、变更审查、行为监控 |
| Schema 投毒 | 参数定义被改 | 必需字段诱导收集、类型放宽 | schema 强校验、变更告警 |
| 工具影身 | 同名假工具 | 注册同名工具 | 工具签名、来源校验 |
| 参数注入 | 响应携带超范围参数 | 工具响应诱导额外参数（74%） | 参数 schema 校验、意图验证 |
| 跨工具链 | 良性调用组合成危害 | 查询→写文件→发邮件（>90%） | 会话依赖图、级联告警 |
| 目标劫持 | 重定向 Agent 目标 | 内容引导计划偏离（EchoLeak） | 计划白名单、目标范围校验 |
| 记忆投毒 | 持久注入 | 恶意记忆跨会话生效 | 记忆写入校验、临时上下文 |
| HITL 绕过 | 骗过人工审批 | 授权伪造、批量混入、确认疲劳 | 强制交互确认 UI、分级审批 |
| 意外代码执行 | 输出当代码 | LLM 生成 shell/SQL 直接执行 | 沙箱、命令白名单、结构化输出 |

## 数据/模型/供应链层

| 攻击 | 原理 | 手法 | 防御 |
|---|---|---|---|
| RAG 投毒 | 知识库注入 | 5 篇文档 90% 操纵（PoisonedRAG） | 文档准入校验、检索层权限 |
| 向量投毒 | embedding 邻近性 | 恶意文档必然被检索 | 写入隔离、投毒审计 |
| 跨租户泄露 | 过滤后置 | ANN 检索后过滤 | 每租户独立索引 |
| 训练数据投毒 | 语料污染 | 后门、Sleeper Agent | 数据源验证、对抗保留集 |
| 微调投毒 | 样本过审 | 教会对抗行为 | 微调数据审查、差异评估 |
| 技能/插件后门 | 市场无审查 | ClawHavoc 模式（824 恶意技能） | 市场审查+签名+监控 |
| 恶意 MCP 服务器 | 分发渠道 | 27.2% 服务器有可利用工具 | 白名单、AIBOM、审计 |
| 依赖混淆 | 包名抢占 | 内网包名被抢注 | 锁定版本、SCA 扫描 |

## 资源/滥用层

| 攻击 | 原理 | 手法 | 防御 |
|---|---|---|---|
| 无界消耗 | 配额/成本耗尽 | 超长输入输出、无限循环 | 速率限制、成本上限、循环检测 |
| 模型提取 | 查询蒸馏 | 大量查询复制行为 | 用量监控、水印、速率限制 |
| 训练数据记忆 | 背诵训练数据 | 对抗提示逐字输出（1%） | 差分隐私、输出过滤、去重 |
