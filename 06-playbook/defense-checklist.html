防御检查清单

防御检查清单

A. 设计阶段

□ 威胁建模：按 OWASP LLM/Agentic/MCP Top 10 + MITRE ATLAS 逐项过
□ 最小自主：Agent 能做什么有明确清单；写操作默认需审批
□ 工具最小范围：每个工具只授权任务所需；读/写分离
□ 系统提示中零密钥、零 PII、零内部 URL
□ 安全逻辑外置（代码层执行，不靠提示词）
□ 沙箱计划：执行环境隔离、默认拒绝出网
□ 每 Agent 独立身份（NHI）+ 短时凭证
□ 日志设计：prompts/工具元数据/工具调用/输出全记录
□ 成本上限 + 速率限制 + 循环检测

B. 上线前（Pre-deployment）

□ 红队评估：promptfoo/PyRIT 跑注入、工具滥用、目标劫持
□ garak 模型层基线扫描
□ MCP 服务器盘点 + 发布者审查 + 版本锁定
□ 工具描述全量导出审查（指令性语言扫描）
□ AIBOM：组件/技能/模型/数据来源清单
□ 出站白名单配置 + DLP 规则
□ 高影响动作 HITL 流程联调
□ 行为基线建立（工具调用/端点/参数模式）
□ 检测告警测试（验证能抓到投毒）

C. 运行中（Runtime）

□ 工具元数据指纹 + 漂移告警（变更即阻断待审）
□ 输入输出分类器在热路径（延迟预算内）
□ 行为偏离告警：新端点/扩参数/异常序列
□ 外泄检测：密钥模式/高熵/base64/批量
□ DLP 检查工具调用参数与出站载荷
□ 技能/服务器/依赖更新走变更审查
□ 用量监控：token/成本/调用次数异常
□ 定期红队（季度 + 重大变更后）
□ 漏洞回归测试在 CI 中持续运行（RAMPART/promptfoo）

D. 关键红线（违规即高危）

□ 系统提示/上下文里有密钥？           → 立即外置
□ Agent 有写权限而无人工审批？         → 加 HITL
□ 第三方 MCP 服务器无审查/无锁定？     → 下线或治理
□ 工具描述可被上游静默修改？           → 加指纹+重新审批
□ Agent 可读敏感数据且可任意出网？     → 阻断出口（这是外泄机器）
□ 无行为监控/无告警？                  → 补检测（否则默认静默失陷）
□ 多租户共享向量库且过滤后置？         → 独立索引

E. 最低可行防御（最小可部署组合）

1. 系统提示零秘密
2. 工具最小权限 + 写操作 HITL
3. 沙箱 + 默认拒绝出网
4. 工具描述指纹 + 漂移阻断
5. 输入分类器（热路径 <50ms）
6. 全量日志（工具调用全参数）
7. 成本/速率限制
8. 上线红队 + CI 回归
