04 工具速查

按用途分类的 AI/Agent 安全工具清单（持续更新）：

  • 红队测试工具 — garak、PyRIT、promptfoo、RAMPART、AgentDojo 等
  • Guardrails 工具 — NeMo、Guardrails AI、LLM Guard、Llama Guard 等
  • MCP / Agent 安全工具 — AI-Infra-Guard、agentseal、pipelock、SHIELDMCP 等
  • 检测与防护服务 — Prompt Shields、Lakera、StackOne、Vigil、Rebuff 等

选择原则：按你要防的攻击面选工具，而不是按品牌。多数生产环境需要组合 2-3 个不同层级的工具。
