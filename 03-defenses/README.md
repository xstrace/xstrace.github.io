# 03 防御技术

防御的核心原则：**纵深防御（Defense in Depth）**——没有单一防护层能完全防住注入，攻击者必须绕过多个独立机制才能成功。

- [输入防护与净化](input-sanitization.md) — 输入过滤、规范化、扫描
- [上下文隔离](context-isolation.md) — 指令/数据分离、定界符、特权层级
- [Guardrails 护栏体系](guardrails.md) — 运行时规则、护栏框架、输出验证
- [Agent 架构加固](agent-hardening.md) — 最小权限、HITL、沙箱、身份管理
- [MCP 生态安全](mcp-security.md) — 元数据指纹、服务器治理、网关
- [监控与检测](monitoring-detection.md) — 行为基线、异常检测、外泄检测
- [红队评估与测试](red-teaming.md) — 红队流程、基准、CI 回归

## 纵深防御五层（PALADIN 框架参考）

1. **输入验证与净化** — 拦截明显注入模式（正则+语义过滤）
2. **上下文隔离与定界** — 系统提示与不可信内容分层、权限层级
3. **行为监控与异常检测** — 工具调用序列/数据访问偏离基线
4. **工具调用授权与沙箱** — 敏感操作人工确认 + 隔离执行环境
5. **输出过滤与验证** — 外泄检测、策略违规、推理受损迹象
