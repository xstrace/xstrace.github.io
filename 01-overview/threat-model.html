威胁模型与攻击面

威胁模型与攻击面

1. 分层威胁模型

AI 系统的攻击面按层次划分，越往下越接近传统安全，越往上越是 AI 特有：

层次 组件 典型攻击面
L1 用户交互层 用户输入、多模态输入（图片/音频/视频） 直接提示注入、越狱、多模态越狱（图像内隐藏文本等）
L2 上下文层 系统提示、检索文档、工具输出、记忆/会话历史 间接提示注入、系统提示泄露、RAG 投毒、记忆投毒
L3 模型层 基座模型、微调权重、embedding 模型 模型投毒/后门、提取攻击、逆向、模型窃取
L4 工具/插件层 MCP Server、插件、函数调用、浏览器自动化 工具投毒、工具元数据篡改、参数注入、工具滥用链
L5 数据层 向量库、知识库、训练数据集、缓存 向量投毒、跨租户泄露、训练数据记忆泄露
L6 执行/编排层 Agent 运行时、编排框架、沙箱 目标劫持、意外代码执行、级联故障、失控 Agent
L7 通信/身份层 Agent 间通信（A2A）、身份与权限、API 伪造消息、身份与权限滥用、重放攻击
L8 供应链层 依赖、模型权重、MCP 服务器分发、技能市场 恶意包/服务器/技能、Rug Pull、依赖混淆
L9 资源层 Token 用量、API 配额、成本 无界消耗（成本攻击/LLM 版 DoS）

2. Agent 特有的攻击面扩展

传统 LLM 应用 vs Agent 应用的关键差异：

传统应用:  用户输入 → LLM → 文本输出        （影响：输出内容）
Agent 应用: 用户输入 → LLM(计划) → 工具调用 → 执行动作 → 真实世界影响
                                      ↑______ 攻击者可污染这里

Agent 引入的新攻击面：

  • 工具调用通道：攻击者通过工具元数据、工具输出、参数描述污染 Agent 决策
  • 工具链：多个"单独看都合法"的调用串成危险序列（跨工具利用链，成功率 >90%）
  • 记忆与持久化：跨会话记忆被污染后持续生效
  • Agent 间通信（A2A）：一个 Agent 的输出成为另一个 Agent 的输入
  • 授权身份：Agent 以非人身份（NHI）执行操作，权限滥用难以被发现

3. MCP 攻击面（2025-2026 增长最快的领域）

MCP（Model Context Protocol）攻击面被 SAFE-MCP（OpenSSF）系统化为 14 个战术类别、80+ 技术，与 MITRE ATT&CK 方法论对齐。5 大高发攻击族：

  1. 工具描述投毒（Tool Poisoning via Metadata）：恶意指令藏在工具 description/schema 里，Agent 无法分辨"能力说明"与"命令"。攻击成功率高达 61.8%–72.8%
  2. 工具输出间接注入：工具返回的数据里携带指令（平均成功率 74%）
  3. MCP 服务器供应链投毒：恶意服务器混入公开平台；27.2% 的服务器暴露可利用工具
  4. Rug Pull 与行为变异：先正常后变恶意的服务器（postmark-mcp 事件：15 个干净版本后 v1.0.16 悄悄加入 BCC 外泄）
  5. 跨工具利用链：良性调用组合成数据外泄管道

4. 攻击者视角：攻击链示例

攻击链 1：间接提示注入 → 数据外泄（EchoLeak 模式）
  恶意邮件/网页/文档(含隐藏指令)
    → Agent 检索/总结时读取
      → Agent 调用工具读取用户数据
        → 通过 Agent 已有权限外发（无点击、无告警）

攻击链 2：工具描述投毒 → 静默外泄（Microsoft 2026 模式）
  修改 MCP 工具 description（名字与摘要不变）
    → 元数据实时更新且无重新审批
      → 用户正常提问时 Agent 按隐藏指令收集敏感数据
        → 附加到合法出站调用中 → 攻击者服务器记录

攻击链 3：恶意技能/服务器 → 供应链后门
  发布恶意 MCP Server / Agent 技能到公共市场
    → 用户安装 → 技能内嵌窃密逻辑（凭证、密钥、邮件）
      → 每次调用执行

5. 攻击者的资产目标

目标 说明 典型手法
数据外泄 文档、数据库、会话、密钥 间接注入、工具投毒、提取攻击
凭证与密钥 API Key、OAuth Token 提示泄露、技能后门、日志抓取
权限滥用 越权操作、提权 混淆代理攻击、身份滥用、授权绕过
系统破坏 RCE、删除文件/资源 不当输出处理、意外代码执行
信誉/认知 错误信息、品牌滥用 深度伪造、RAG 误导、自动差评
资源消耗 成本、算力 无界消耗、无限循环、超长输出
